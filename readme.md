# legseight_bot 

[![Ruby Version](https://img.shields.io/badge/Ruby-3.x%2F4.x-red.svg)](https://www.ruby-lang.org/)
[![Telegram Bot API](https://img.shields.io/badge/Telegram%20Bot%20API-v0.20-blue.svg)](https://github.com/atipik/telegram-bot-ruby)

**legseight_bot** — це Telegram-бот на мові Ruby, призначений для автоматичного отримання та відображення заголовків вебсторінок (`<title>`) за наданим URL-посиланням.

Бот використовує вбудовану бібліотеку `Net::HTTP` для виконання GET-запитів із підтримкою HTTP-редиректів, а також бібліотеку `Nokogiri` для розбору HTML-документів.

##  Встановлення та налаштування

Дотримуйтесь цих кроків, щоб розгорнути та запустити бота локально:

### 1. Клонування репозиторію
```bash
git clone https://github.com/Nazar-Dron/-7-Telegram--Ruby-gem-.git
cd -7-Telegram--Ruby-gem-
```

### 2. Встановлення залежностей (Gems)
Переконайтеся, що у вас встановлено `Ruby` та `Bundler`, після чого виконайте:
```bash
bundle install
```

Скрипт встановить наступні необхідні геми з `Gemfile`:
* `telegram-bot-ruby` — обгортка для Telegram Bot API.
* `nokogiri` — HTML/XML парсер.
* `dotenv` — завантаження змінних середовища з файлу `.env`.

### 3. Налаштування токена
Створіть файл `.env` у кореневій папці проєкту:
```bash
echo "TELEGRAM_BOT_TOKEN=ваш_токен_від_botfather" > .env
```
Замініть `ваш_токен_від_botfather` на реальний HTTP API токен, отриманий від [@BotFather](https://t.me/BotFather).

### 4. Запуск бота
```bash
bundle exec ruby bot.rb
```

##  Інструкція з використання та список команд

Після запуску бота відкрийте діалог із ним у Telegram і використовуйте доступні команди та інпути:

| Команда / Ввід | Опис та дія | Приклад |
| :--- | :--- | :--- |
| `/start` | Запускає бота та виводить привітальне повідомлення з інструкцією. | `/start` |
| `<URL адреса>` | Приймає текстове посилання на вебсайт, робить HTTP GET-запит і повертає вміст тегу `<title>`. | `github.com` або `https://ruby-lang.org` |

### Приклад роботи:

1. **Користувач:** `/start`
   * **Бот:** `Привіт! Надішли мені URL вебсайту (наприклад, github.com або https://ruby-lang.org), і я знайду його заголовок!`
2. **Користувач:** `github.com`
   * **Бот:** ` Отримую дані з github.com...`
   * **Бот:** ` Заголовок сторінки:`  
     `GitHub: Let’s build from here · GitHub`

## ️ Обробка помилок

Бот має вбудований захист від збоїв за допомогою блоку `rescue`:
* **Некоректний URL:** Інформує про помилку вводу синтаксису адреси.
* **Неіснуючий домен / Обрив мережі:** Повідомляє про неможливість з'єднатися з сервером без падіння процесу бота.
